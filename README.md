# Portfólio Pessoal

Portfólio simples, moderno e responsivo para apresentar projetos, habilidades e redes sociais.

## Como usar

1. Extraia o ZIP.
2. Abra a pasta no Visual Studio Code.
3. Abra `index.html` no navegador ou use a extensão Live Server.
4. Edite os textos e links no `index.html`.

## Personalização

### Redes sociais
No final do `index.html`, substitua os `href="#"` por seus links reais:

- Instagram
- GitHub
- LinkedIn

Também altere `seuemail@email.com` para seu e-mail.

### Projetos
Na seção `#projetos`, altere os títulos, descrições, tecnologias e links dos cards.

### Foto
A pasta `assets/img/` está preparada caso você queira adicionar uma foto de perfil depois.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Layout responsivo
- Menu mobile
- Animações e interações simples

Não é necessário banco de dados, PHP ou servidor para executar esta versão.
