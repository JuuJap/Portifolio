# Portfólio Pessoal

Este projeto consiste em um portfólio pessoal desenvolvido para apresentar minha trajetória na área de tecnologia, reunindo meus principais projetos, habilidades, tecnologias estudadas e formas de contato.

O objetivo do portfólio é centralizar meus trabalhos e experiências acadêmicas em um único espaço, permitindo que outras pessoas conheçam os projetos que desenvolvi e minhas áreas de interesse dentro da tecnologia.

## Sobre o projeto

O portfólio foi desenvolvido com uma proposta simples, moderna e objetiva, priorizando uma boa experiência de navegação e a apresentação organizada das informações.

A página conta com:

* Apresentação pessoal;
* Seção sobre mim;
* Projetos desenvolvidos;
* Tecnologias e habilidades;
* Links para redes sociais;
* Informações de contato;
* Design responsivo para diferentes tamanhos de tela;
* Menu de navegação adaptado para dispositivos móveis.

## Projetos apresentados

Entre os projetos apresentados no portfólio estão trabalhos acadêmicos e projetos de desenvolvimento web, incluindo:

### Divine Essence

Loja virtual de perfumes desenvolvida com foco na integração entre front-end, back-end e banco de dados. O projeto conta com catálogo de produtos, cadastro e login de usuários, autenticação e interface responsiva.

**Tecnologias:** HTML5, CSS3, JavaScript, PHP e MySQL.

### ERP — Velas S. Tomé

Sistema de gestão desenvolvido como projeto técnico, reunindo funcionalidades voltadas ao gerenciamento de clientes, produtos, vendas, pedidos e controle geral.

**Tecnologias:** HTML5, CSS3, JavaScript, PHP e MySQL.

### Controle de Chamados

Sistema desenvolvido para gerenciamento de chamados de suporte técnico, permitindo registrar, consultar e acompanhar solicitações, além de apresentar informações através de um dashboard.

**Tecnologias:** HTML5, CSS3, Bootstrap, JavaScript, PHP e MySQL.

## Tecnologias utilizadas no portfólio

* **HTML5** — estrutura e organização das páginas;
* **CSS3** — estilização, layout e responsividade;
* **JavaScript** — interações e funcionalidades da interface.

## Responsividade

O portfólio foi desenvolvido utilizando técnicas de design responsivo, permitindo que a interface se adapte automaticamente a diferentes resoluções e tamanhos de tela.

O site pode ser acessado em:

* Computadores;
* Notebooks;
* Tablets;
* Smartphones.

Este portfólio faz parte do meu processo de desenvolvimento profissional na área de tecnologia e tem como finalidade demonstrar, de forma prática, conhecimentos adquiridos durante meus estudos e projetos.
